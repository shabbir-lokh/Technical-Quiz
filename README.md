# QuizMaster – Interactive Quiz Application 🎯

## 📌 Project Overview

QuizMaster is a simple, interactive web-based quiz application developed using HTML, CSS, and JavaScript. It allows users to enter their name, choose a quiz category, answer multiple-choice questions, and view their final score.

The project demonstrates fundamental JavaScript concepts, including DOM manipulation, event handling, arrays, objects, functions, and conditional statements.

## ✨ Features

- 👤 **Personalized Greeting:** Enter your name to begin the quiz.
- 📚 **Category Selection:** Choose HTML, JavaScript, or all questions.
- ❓ **Multiple-Choice Questions:** Answer interactive quiz questions.
- ✅ **Instant Feedback:** See whether your answer is correct or incorrect.
- 📊 **Progress Tracking:** View the current question and quiz progress.
- 🏆 **Score Calculation:** Automatically calculate your final score.
- 🔄 **Restart Quiz:** Start again and try to improve your score.
- 📱 **Responsive Design:** Use the application on desktop, tablet, and mobile screens.

## 🛠️ Technologies Used

- **HTML5** – Structures the webpage.
- **CSS3** – Styles the interface and supports responsive layouts.
- **JavaScript** – Implements quiz logic and interactive features.

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code or another code editor.
3. Ensure `index.html`, `style.css`, and `script.js` are in the correct locations.
4. Open `index.html` in your browser, or use the Live Server extension in VS Code.
5. Enter your name, select a category, and start answering questions.
